# rules-telegram-bot

Telegram-бот, который показывает правила чата по главам и дает админам управлять ими прямо из чата — без правок JSON вручную. Стек: Go 1.26, [go-telegram/bot](https://github.com/go-telegram/bot), данные в `rules.json`.

## Как это выглядит

Пользователь пишет `Правила` → получает заголовок и кнопки глав:

> 📜 Правила чата. Выберите главу:
> [ 1. КОНФЛИКТЫ ] [ 2. ОБЩЕНИЕ И КОНТЕНТ ] [ 3. ГОЛОСОВОЙ ЧАТ ]

Нажатие на главу показывает пункты с автоматической нумерацией:

> 📌 1. КОНФЛИКТЫ
>
> 1.1 Запрещены любые конфликты. …
> 1.2 Запрещены любые оскорбления …

Админ пишет `/rules_admin` → меню, где у каждой главы свой ряд `✏️ 🗑 👁`: открыть пункты, удалить (с подтверждением), скрыть/показать. Внутри главы то же самое для пунктов, плюс ✏️ просит прислать новый текст следующим сообщением. Кнопки привязаны к вызвавшему — чужое меню нажать нельзя. `/rules_toggle` скрывает/показывает правила целиком, `/admin_title` меняет заголовок.

## Quick start

```bash
cp .env.example .env   # BOT_TOKEN, TARGET_CHAT_ID, ADMIN_IDS
go run ./cmd/bot
```

или в Docker:

```bash
cp .env.example .env
docker compose up --build
```

Правила лежат в `rules.json` (монтируется в контейнер):

```json
{
  "title": "📜 Правила чата. Выберите главу:",
  "visible": true,
  "chapters": [
    { "title": "КОНФЛИКТЫ", "visible": true,
      "items": [{ "text": "Запрещены любые конфликты.", "visible": true }] }
  ]
}
```

Проверки: `go vet ./...`, `go test ./... -race`, `go build ./...`.
